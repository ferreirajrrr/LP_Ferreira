# Portfólio Pessoal | Ferreira Júnior

## O Projeto
Este repositório guarda o código da minha landing page pessoal. O objetivo principal do site é documentar meu aprendizado contínuo e minha transição de carreira da área audiovisual para a Tecnologia da Informação. Todo o código foi escrito de forma limpa e estruturada, pensando tanto na leitura por líderes técnicos quanto na indexação por sistemas automatizados de recrutamento.

## Tecnologias Aplicadas
* HTML5 estruturado com foco em semântica
* CSS3 puro utilizando variáveis de ambiente, paleta de cores customizada e efeitos de profundidade
* JavaScript leve aplicado apenas para mapear a rolagem da tela e garantir interações suaves

## Estrutura da Página
* Perfil: Um resumo sobre minha graduação em Ciências da Computação e meu perfil analítico.
* Mapa de Habilidades: Uma representação visual das tecnologias que domino e das que estou estudando no momento, incluindo tópicos de Inteligência Artificial.
* Vitrine de Projetos: Acesso rápido aos meus experimentos práticos e aplicações em funcionamento.

## Como visualizar
Basta fazer o download dos arquivos ou o clone deste repositório em sua máquina local. Depois disso, abra o arquivo index.html no navegador de sua preferência. Nenhuma instalação ou configuração adicional é exigida.

## Origem
Desenvolvido em Fortaleza, Ceará. Código aberto para inspeção e estudos.
